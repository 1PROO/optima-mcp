Strict 3-Step Safety Protocol

Enforced natively via SKILL.md and the optima://protocol/strict-rules MCP resource.

optima://protocol/strict-rules
STEP 01 inspect_source

Zero-Flood Schema Discovery

Streams the dataset locally and returns ONLY column names, types, null counts, numeric min/max/mean, and at most 3 sample rows.

STEP 02 dry_run_validate

Mandatory Pydantic & Anomaly Guard

Validates column mappings and flags negative-margin traps, carton-vs-unit mismatches, and storage or budget conflicts before computing.

STEP 03 solve_*

Deterministic Solve + Audit Trail

Executes HiGHS or OR-Tools to output exact optimal plans, KPIs, skipped opportunities with mathematical reasons, and infeasibility diagnostics.

Install in 10 Seconds

Runs directly from GitHub via uvx. Works with Claude Desktop, Antigravity, Cursor, Windsurf, and any MCP client.

Copy and paste this single prompt into Antigravity, Claude Code, Cursor, or Windsurf: 

Install the MCP plugin and skill from https://github.com/1PROO/optima-mcp following its Agent Auto-Install block.

Add this to claude_desktop_config.json or .mcp.json (requires uv): 

{
  "mcpServers": {
    "optima-mcp": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://github.com/1PROO/optima-mcp",
        "optima-mcp"
      ]
    }
  }
}
